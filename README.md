# FindUs 설문 랜딩페이지

장기 실종아동 문제와 AI 현재 모습 추정 아이디어를 소개하고 Microsoft Forms 인식조사로 연결하는 정적 한 페이지 사이트입니다. HTML/CSS/JavaScript만 사용하며 설치나 빌드가 필요 없습니다.

## 파일

- `index.html`: 콘텐츠, 접근성 마크업, 설문 링크
- `styles.css`: 파랑 한 계열의 디자인과 모바일 반응형 스타일
- `script.js`: 푸터 연도 갱신, 스크롤 진행률, 설문 주제 안내의 스크롤 진행률
- `assets/favicon.svg`: FindUs 방패 아이콘
- `.nojekyll`: GitHub Pages에서 정적 파일을 그대로 제공

폰트는 Google Fonts의 Noto Sans KR을 사용합니다. 외부 폰트를 불러오지 못할 경우 시스템 폰트로 표시됩니다. 첫 화면은 서로 바라보는 사용자 제공 사진(`assets/time-portrait.png`)을 사용합니다. 어린 시절과 성인 모습 모두 설명용 예시로 표시합니다. 아이디어 카드는 사용자 제공 사진을 바탕으로 내장 imagegen 도구로 재구성한 AI 생성 예시(`assets/time-comparison-v2.png`)의 왼쪽 어린 시절과 오른쪽 성인 모습을 CSS로 나누어 재사용합니다. 실제 실종 사례나 검증된 AI 추정 결과가 아닙니다. 원본은 `assets/time-portrait.png`에 보존합니다. 아이디어 설명과 설문 주제에는 자체 SVG 일러스트를 사용합니다. 신원 정보 제공 범위는 경찰청 안전Dream의 공개 범위로 안내합니다.

## 로컬 실행

프로젝트 폴더에서 다음 명령을 실행한 뒤 `http://localhost:8000`을 엽니다.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

`index.html`을 브라우저에서 직접 열어도 사용할 수 있습니다.

## GitHub Pages 배포

1. GitHub에 이 페이지용 저장소를 만들고 이 폴더의 파일들을 저장소 루트에 업로드합니다. 숨김 파일인 `.nojekyll`도 포함합니다.
2. 저장소의 **Settings → Pages → Build and deployment**에서 **Source: Deploy from a branch**를 선택합니다.
3. **Branch: main**, **Folder: / (root)**를 선택하고 저장합니다. 다른 브랜치에 업로드했다면 해당 브랜치를 선택합니다.
4. 배포가 끝나면 Pages 설정 화면의 사이트 링크를 확인합니다. 프로젝트 저장소의 기본 주소는 `https://<사용자명>.github.io/<저장소명>/`입니다.

배포 소스로 선택한 브랜치의 파일을 변경하면 GitHub Pages가 다시 배포합니다. 모든 로컬 리소스 경로는 `./` 상대 경로로 작성해 저장소명 하위 경로에서도 작동합니다.

공식 안내: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## 설문 연결

설문: https://forms.cloud.microsoft/r/7tnUFtYiPE

첫 화면과 마지막에 “3분 설문조사 참여하기” 버튼을 배치하며 Microsoft Forms를 새 탭으로 엽니다. 스크롤 진행바는 내용을 살펴보는 위치만 표시합니다. 설문 버튼은 처음부터 활성화되어 있으며 JavaScript 없이도 작동합니다. 링크 변경 시 `index.html`의 두 참여 버튼을 함께 변경합니다. 이 페이지는 설문 응답이나 제보 내용을 입력받거나 저장하지 않습니다.

## 확인 항목

- 모바일과 데스크톱에서 텍스트 및 가상 인물 카드가 잘리지 않는지
- 마지막 설문 버튼이 Microsoft Forms 설문을 새 탭으로 여는지
- 키보드 포커스와 본문 바로가기 링크가 작동하는지
- AI 추정 이미지 안내와 개발·수요 검증 단계 안내가 표시되는지
- GitHub Pages 배포 후 CSS, JavaScript, 파비콘이 정상 로드되는지

## 비교 이미지 제작 프롬프트

내장 imagegen 편집 사용. 제공 사진의 한국인 어린이·성인 얼굴, 짧은 검은 머리와 회색·흰색 티셔츠를 유지하며 정면 상반신 초상으로 재구성. 왼쪽 어린이·오른쪽 성인, 같은 크기의 두 영역, 부드러운 조명과 청회색 배경. 각 영역 중앙에 얼굴 배치, 텍스트·연도·로고 없음. 설명용 예시로 사용.

페이지의 주색은 `#163D65`, 밝은 배경은 `#EAF3FA`, 기본 바탕은 흰색입니다. 일러스트는 남색·청록 포인트와 자연스러운 피부색을 사용해 내용이 구분되도록 합니다.

스크롤 진행바는 작은 청록색 아이가 큰 두 부모 사이로 이동하는 단순한 사람 그림으로 표현합니다. 쿠키 장식이나 게임 캐릭터 스타일을 사용하지 않습니다. 화면의 문구·퍼센트·단계 숫자는 숨기고 스크린리더에는 진행률을 제공합니다. 지나온 길은 실선·남은 길은 점선이며, 도착하면 작은 하트가 표시됩니다. 그림은 코드로 작성한 SVG이며 실제 실종 사례나 찾기 결과를 의미하지 않습니다.
